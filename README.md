# 디폼 도안

사진을 실제 디폼블럭 조립에 참고할 작은 사각 도안으로 바꾸는 Android 앱의 배포 파일 저장소입니다.

[0.1.5 검토판 설치 파일 다운로드](https://github.com/selfness-byte/dform-pattern-updates/releases/download/v0.1.5/DformPattern-0.1.5-debug.apk) · [버전별 배포 기록](https://github.com/selfness-byte/dform-pattern-updates/releases)

Android 9 이상을 지원합니다. **사진 선택하기 → 물체 찾기**로 남길 물체를 확인하세요. 여러 배경색과 가장자리 연결로 물체 후보를 찾고, 판단이 애매하면 사진 전체를 유지합니다. 잘못 잡히면 **물체 직접 선택**을 누르고 남길 물체를 한 번 누르세요. 흰 테두리는 이동·크기 조정할 수 있습니다. 물체와 배경의 색이 비슷하거나 사진이 복잡하면 직접 영역을 맞춰야 합니다.

기본 긴 변 16칸·최대 6색의 작은 사각 카툰 도안, 선명한 캐주얼 랜덤 배색, 블록 사이 흰 틈을 채운 윤곽·음영 표현을 지원합니다. 현재 도안의 중앙 영역 소형화와 색만 바꾸기, 되돌리기, 수동 색 편집, 색상별 수량, PNG/PDF 저장을 제공합니다. 랜덤 색 옵션을 끄면 사진 색을 사용합니다.

앱 하단의 **업데이트 확인**에서 아래 기본 주소의 버전과 비교합니다. 기존에 저장한 다른 주소는 유지하며 **업데이트 주소 설정 / 변경**에서 바꿀 수 있습니다.

```text
https://raw.githubusercontent.com/selfness-byte/dform-pattern-updates/main/updates/update.json
```

업데이트 정보는 `updates/update.json`에 보관합니다. 새 버전에서는 APK를 먼저 올리고 이 파일을 갱신합니다. 사진 변환과 도안 편집은 기기에서 처리하고 사진·도안을 업데이트 서버에 전송하지 않습니다.

현재 배포는 검토용 디버그 서명 APK입니다. Samsung SM-S908N에서 설치·실행, 저장된 12×16칸·192개·6색 도안 유지와 합성 입력의 물체 선택·배경 터치 거부·드래그 구분을 확인했습니다. 모든 사진의 인식 정확도나 모든 기기 기능을 검증한 것은 아닙니다. 색상표는 제품 미확정 예시이며 직사각형의 모든 칸을 조립합니다. 실제 제품의 색과 치수는 별도로 확인하세요.
