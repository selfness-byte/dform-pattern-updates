# 디폼 도안

사진을 디폼블럭 조립에 참고할 평면 도안으로 바꾸는 Android 앱의 배포 파일 저장소입니다.

[0.1.1 검토판 설치 파일 다운로드](https://github.com/selfness-byte/dform-pattern-updates/releases/download/v0.1.1/DformPattern-0.1.1-debug.apk) · [버전별 배포 기록](https://github.com/selfness-byte/dform-pattern-updates/releases)

Android 9 이상에서 APK를 열어 설치합니다. 기본 최대 8색이며 4·6·8·12색 선택, 블럭 형태 미리보기, 색상별 수량, 기존 도안 색 줄이기와 되돌리기, PNG/PDF 저장을 지원합니다.

앱 하단의 **업데이트 주소 설정 / 변경**에 다음 주소를 저장한 뒤 **업데이트 확인**을 누르세요.

```text
https://raw.githubusercontent.com/selfness-byte/dform-pattern-updates/main/updates/update.json
```

업데이트 정보는 `updates/update.json`에 보관합니다. 새 버전에서는 APK를 먼저 올리고 이 파일의 버전과 다운로드 주소를 갱신합니다. 사진 변환과 도안 편집은 기기에서 처리합니다.

현재 배포는 검토용 디버그 서명 APK입니다. 실제 휴대폰 실행과 앱에서의 통신은 아직 검증하지 않았습니다. 색상표는 제품 미확정 예시이며 블럭 표현은 실제 제품의 치수 도면이 아닙니다.
